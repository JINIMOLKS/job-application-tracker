# 💼 Job Application Tracker

A simple web application built with Django to manage and track job applications.

## 🚀 Features

- Add job applications
- View applications
- Edit applications
- Delete applications
- Search applications by company
- Filter applications by status
- Dashboard with application statistics
- Colourful and responsive user interface

## 🛠️ Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap
- Git
- GitHub

## 📊 Application Status

The application supports four statuses:

- Applied
- Interview
- Selected
- Rejected
